# Addaix

Making it easier to make AI-enabled applications: open-source Python (and some TypeScript) packages for calling models, building context and retrieval, and working with AI agents.

## Models, prompts and context

* [aix](https://github.com/addaix/aix): AI eXtensions, one facade over model providers
* [oa](https://github.com/addaix/oa): Python interface to OpenAI
* [pyrompt](https://github.com/addaix/pyrompt): manage, share and search prompt templates
* [contaix](https://github.com/addaix/contaix): tools to make contexts for AI
* [byok](https://github.com/addaix/byok): bring your own AI keys (TypeScript)
* [nyms](https://github.com/addaix/nyms): reversible pseudonymisation of text before it reaches an AI

## Embeddings and retrieval

* [imbed](https://github.com/addaix/imbed), [imbed_data_prep](https://github.com/addaix/imbed_data_prep): tools to work with embeddings
* [ef](https://github.com/addaix/ef), [app_ef](https://github.com/addaix/app_ef): embeddings flow
* [raglab](https://github.com/addaix/raglab): tools to make RAG-based applications
* [kc](https://github.com/addaix/kc): knowledge context, retrievable and attributable (design stage)
* [citeget](https://github.com/addaix/citeget): find and acquire academic references

## Agents and skills

* [aw](https://github.com/addaix/aw), [aw_agents](https://github.com/addaix/aw_agents), [app_aw_agents](https://github.com/addaix/app_aw_agents): agentic workflows and ready-to-use agents
* [ayn](https://github.com/addaix/ayn): find and access the agents you need
* [skill](https://github.com/addaix/skill), [toolery](https://github.com/addaix/toolery): search and manage agent skills and tools
* [coact](https://github.com/addaix/coact): reuse skills across the agent stack
* [opsward](https://github.com/addaix/opsward): diagnose and maintain a project's agent setup
* [aikb](https://github.com/addaix/aikb): CRUD for AI project knowledge bases
* [ge](https://github.com/addaix/ge): agentic tools for GitHub

## Working with agents

* [astern](https://github.com/addaix/astern): mine past Claude Code sessions
* [acquaint](https://github.com/addaix/acquaint): people, for AI agents
* [ductus](https://github.com/addaix/ductus): which parts of a text read as machine-written, and why
* [penlike](https://github.com/addaix/penlike): model how an author writes
* [ideadump](https://github.com/addaix/ideadump): capture and research ideas
